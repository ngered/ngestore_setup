# NGE Es'tore — setup du client

Télécharger et lancer **[NGEStore_setup.exe](https://github.com/ngered/ngestore_setup/raw/refs/heads/main/NGEStore_setup.exe)**.

- Version : 1.1.0.4
- Installation par utilisateur, sans droits d'administrateur, dans `C:\Outils\NgeStore` (modifiable).
- Le runtime .NET 10 est installé avec le client seulement si le poste ne l'a pas.
- Le client se met ensuite à jour automatiquement depuis le catalogue NGE Es'tore.
